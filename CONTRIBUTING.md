# Contributing

Thanks for helping. This is a small, single-purpose template, so please:

1. Open an issue first, describing the problem or idea, before sending a pull request.
2. Keep Air Watch read-only. Changes that control devices or message anyone besides the owner won't be merged.
3. Run the tests before submitting: `python3 -m unittest discover -s tests`
4. If you change `script/airwatch.py`, update the copy embedded in `skills/air-watch-getting-started/SKILL.md` so they stay identical, and add a CHANGELOG entry.

For bugs, use the bug report form and paste the output of "diagnose".
