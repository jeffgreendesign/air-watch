# Security

Air Watch reads your Airthings API keys from environment variables and never prints or stores them in files.

To report a security problem (for example, a way the keys could leak), please don't open a public issue. Use GitHub's private reporting instead: **Security > Report a vulnerability** on this repo.

If you think your Airthings API client was exposed, delete it in the Airthings Dashboard (Integrations > API) and create a new one.
